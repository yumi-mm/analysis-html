# WebApp 充值档位订单分析（2026-05-01 ～ 2026-05-31）

> 口径依据：`liaoyu-data-analysis` skill  
> 分析对象：2026 年 5 月 **WebApp 端**各充值档位的订单数量、用户数、金额分布  
> 主表：`dwd_finance_recharge_i_d`（财务 DWD，体积小，推荐）；埋点 `server_log_data_rt` 仅作分周补充

---

## ⚠️ 成本说明

`server_log_data_rt` 扫描 31 天约 **290GB**，超出单 SQL 限额（400GB Complexity×2）。  
**解决方案：优先用 `dwd_finance_recharge_i_d`（财务 DWD），体积约 1/30，无成本问题。**

| 方案 | 表 | 扫描量 | 适用场景 |
|------|-----|--------|---------|
| ✅ 推荐：DWD 财务版 | `dwd_finance_recharge_i_d` | ~几 GB | 档位/金额统计 |
| ⚠️ 分周埋点版 | `server_log_data_rt`（按周拆分） | ~70GB/周 | 需要 appType 精确区分时 |

## 一、各档位订单数量（DWD 财务版，推荐）

```sql
-- WebApp 各充值档位订单数量（2026-05，dwd_finance_recharge_i_d）
-- platform_id 36=CHAMET_WEBAPP，40=CHAMET_WEBAPP_PC
SELECT
    ROUND(price, 2)                                               AS 充值档位_USD,
    COUNT(1)                                                      AS 订单数量,
    COUNT(DISTINCT userid)                                        AS 付费用户数,
    ROUND(SUM(price), 2)                                          AS 总充值金额_USD,
    ROUND(SUM(price) / COUNT(DISTINCT userid), 2)                 AS ARPPU_USD,
    ROUND(COUNT(1) * 100.0 / SUM(COUNT(1)) OVER (), 2)           AS 订单占比_pct
FROM chamet_data.dwd_finance_recharge_i_d
WHERE ds BETWEEN '20260501' AND '20260531'
  AND platform_id IN (36, 40)
GROUP BY ROUND(price, 2)
ORDER BY ROUND(price, 2) ASC
;
```

## 一附：埋点版（分周拆分，避免超限）

> 若必须用埋点 log_id=91 口径（与趋势图完全一致），将 31 天拆成 4～5 周分别执行，每次扫描 ~70GB，在限额内。  
> 结果用 UNION ALL 或在 Excel 中合并。

```sql
-- 第 1 周：2026-05-01 ～ 2026-05-07（约 70GB，在限额内）
-- 修改 ds 范围即可复用：05-08~05-14 / 05-15~05-21 / 05-22~05-31
WITH log_raw AS (
    SELECT
        CAST(userid AS BIGINT)                        AS userid,
        GET_JSON_OBJECT(extra, '$.orderId')           AS order_id,
        CAST(COALESCE(
            GET_JSON_OBJECT(extra, '$.money'),
            GET_JSON_OBJECT(extra, '$.rechargeMoney'),
            GET_JSON_OBJECT(extra, '$.price')
        ) AS DOUBLE)                                  AS price_usd,
        CAST(COALESCE(
            GET_JSON_OBJECT(extra, '$.appType'),
            GET_JSON_OBJECT(extra, '$.apptype')
        ) AS BIGINT)                                  AS app_type
    FROM chamet_data.server_log_data_rt
    WHERE ds BETWEEN '20260501' AND '20260507'   -- ← 每次改这里
      AND log_id = '91'
),
dedup AS (
    SELECT userid, order_id, price_usd
    FROM (
        SELECT userid, order_id, price_usd,
               ROW_NUMBER() OVER (PARTITION BY order_id ORDER BY price_usd DESC) AS rn
        FROM log_raw
        WHERE app_type IN (36, 40)
          AND order_id IS NOT NULL
          AND price_usd > 0
    ) t WHERE rn = 1
)
SELECT
    ROUND(price_usd, 2)                                     AS 充值档位_USD,
    COUNT(1)                                                AS 订单数量,
    COUNT(DISTINCT userid)                                  AS 付费用户数,
    ROUND(SUM(price_usd), 2)                                AS 总金额_USD
FROM dedup
GROUP BY ROUND(price_usd, 2)
ORDER BY ROUND(price_usd, 2) ASC
;
-- 四个周期：05-01~07 / 05-08~14 / 05-15~21 / 05-22~31
-- 将四次结果在 Excel 中按档位合并 SUM
```

## 二、各档位订单数量 + 区间汇总（DWD 财务版）

> 精确档位明细与区间合并（≤$1 / $1-3 / $3-5 等）一次输出，与 HTML 报告金额分布图口径一致。

```sql
-- WebApp 各充值档位 + 区间汇总（2026-05，dwd_finance_recharge_i_d）
WITH base AS (
    SELECT
        userid,
        ROUND(price, 2) AS price_usd,
        CASE
            WHEN price <= 1              THEN '≤$1'
            WHEN price <= 3              THEN '$1-3'
            WHEN price <= 5              THEN '$3-5'
            WHEN price <= 10             THEN '$5-10'
            WHEN price <= 30             THEN '$10-30'
            WHEN price <= 50             THEN '$30-50'
            ELSE                              '>$50'
        END AS price_bucket
    FROM chamet_data.dwd_finance_recharge_i_d
    WHERE ds BETWEEN '20260501' AND '20260531'
      AND platform_id IN (36, 40)
)
-- 精确档位
SELECT
    '精确档位'                                          AS 维度,
    CAST(price_usd AS STRING)                          AS 档位,
    COUNT(1)                                           AS 订单数量,
    COUNT(DISTINCT userid)                             AS 付费用户数,
    ROUND(SUM(price_usd), 2)                           AS 总金额_USD,
    ROUND(COUNT(1) * 100.0 / SUM(COUNT(1)) OVER (), 2) AS 订单占比_pct
FROM base
GROUP BY price_usd

UNION ALL

-- 区间汇总
SELECT
    '区间汇总'                                          AS 维度,
    price_bucket                                       AS 档位,
    COUNT(1)                                           AS 订单数量,
    COUNT(DISTINCT userid)                             AS 付费用户数,
    ROUND(SUM(price_usd), 2)                           AS 总金额_USD,
    ROUND(COUNT(1) * 100.0 / SUM(COUNT(1)) OVER (), 2) AS 订单占比_pct
FROM base
GROUP BY price_bucket

ORDER BY 维度 DESC, 总金额_USD DESC
;
```

## 三、按日期 × 档位明细（每日各档位订单量趋势，DWD 财务版）

> 用于查看各档位在 5 月的日趋势，判断是否有档位在特定日期激增/跌落。

```sql
-- WebApp 每日 × 档位订单量（2026-05，dwd_finance_recharge_i_d）
SELECT
    ds                                         AS 日期,
    ROUND(price, 2)                            AS 充值档位_USD,
    COUNT(1)                                   AS 订单数量,
    COUNT(DISTINCT userid)                     AS 付费用户数,
    ROUND(SUM(price), 2)                       AS 总金额_USD
FROM chamet_data.dwd_finance_recharge_i_d
WHERE ds BETWEEN '20260501' AND '20260531'
  AND platform_id IN (36, 40)
GROUP BY ds, ROUND(price, 2)
ORDER BY ds ASC, ROUND(price, 2) ASC
;
```

## 五、三口径汇总对账

> 将埋点版、财务 DWD 版、报表版三个口径的总订单数 / 总金额并排对比，快速定位差异。

```sql
-- 三口径对账：总订单数 & 总金额（2026-05 WebApp）
SELECT '埋点log91'    AS 口径, order_cnt, user_cnt, total_usd FROM (
    WITH raw AS (
        SELECT
            GET_JSON_OBJECT(extra, '$.orderId') AS oid,
            CAST(userid AS BIGINT)              AS uid,
            CAST(COALESCE(
                GET_JSON_OBJECT(extra, '$.money'),
                GET_JSON_OBJECT(extra, '$.rechargeMoney'),
                GET_JSON_OBJECT(extra, '$.price')
            ) AS DOUBLE)                        AS amt,
            CAST(COALESCE(
                GET_JSON_OBJECT(extra, '$.appType'),
                GET_JSON_OBJECT(extra, '$.apptype')
            ) AS BIGINT)                        AS atype
        FROM chamet_data.server_log_data_rt
        WHERE ds BETWEEN '20260501' AND '20260531'
          AND log_id = '91'
    ),
    dedup AS (
        SELECT uid, oid, amt
        FROM (SELECT uid, oid, amt, ROW_NUMBER() OVER (PARTITION BY oid ORDER BY amt DESC) rn FROM raw WHERE atype IN (36,40) AND oid IS NOT NULL AND amt > 0) t WHERE rn=1
    )
    SELECT COUNT(1) AS order_cnt, COUNT(DISTINCT uid) AS user_cnt, ROUND(SUM(amt),2) AS total_usd FROM dedup
) t1

UNION ALL

SELECT '报表rpt' AS 口径, order_cnt, user_cnt, total_usd FROM (
    SELECT
        SUM(recharge_order_num)     AS order_cnt,
        SUM(recharge_user_num)      AS user_cnt,
        ROUND(SUM(recharge_money_usd), 2) AS total_usd
    FROM chamet_data.rpt_ly_webapp_d_report
    WHERE ds BETWEEN '20260501' AND '20260531'
) t2
;
```

## 备注

| 项 | 说明 |
|---|---|
| `orderId` 为空 | WebApp log_id=91 的 `orderId` 在部分场景下为 NULL，去重时可回退到 `userid + recharge_time` 窗口 |
| 档位精度 | `price_usd` 为 DOUBLE，建议 `ROUND(price_usd, 2)` 后再 GROUP BY，避免浮点不等 |
| 时区 | 库内时区，如需换算 UTC 在 `recharge_time` 字段上 `DATEADD` |
| T+1 延迟 | 若查询当天数据，`ds` 使用昨日 |
