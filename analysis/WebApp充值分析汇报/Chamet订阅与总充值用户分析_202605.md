# Chamet 订阅用户 vs 总充值用户（2026-05-01 ～ 2026-05-31）

> 口径依据：`liaoyu-data-analysis` skill  
> 分析对象：**Chamet 谷歌渠道**（`t_googlepay_recharge`）2026 年 5 月充值  
> 输出：订阅用户数、谷歌总充值用户数、订阅用户占比；**订阅总金额、谷歌总充值金额、订阅金额占比**

---

## 口径说明

| 项 | 约定 |
|---|---|
| 时间范围 | 充值发生时间落在 `2026-05-01` ～ `2026-05-31` |
| 分区 | `t_googlepay_recharge` **无 `ds` 分区**，仅用 `pay_time` 过滤 |
| **谷歌总充值** | `t_googlepay_recharge` 中当月有成功订单的去重 `userid` / 金额合计（含普通充值 + 订阅） |
| **订阅** | 同上表中 `product_id LIKE '%monthly_pass%'` 的订单 |
| 成功订单 | `recharge_status = 1 AND order_status = 1` |
| 用户去重 | `COUNT(DISTINCT userid)` |
| 占比 | 订阅用户数 ÷ 谷歌总充值用户数；订阅金额 ÷ 谷歌总充值金额 |

**说明**

- 与优化方案「**谷歌订阅占谷歌总订单 3%**」口径一致，分子分母均来自 `t_googlepay_recharge`。
- 订阅识别字段（`product_id`）已通过 **步骤 0 诊断** 确认。

## 步骤 0：诊断订阅订单识别字段（先跑）

### 0.1 谷歌充值订单中 menu_group_id / product_id 分布

```sql
-- 查看 5 月谷歌充值订单的商品分组，定位订阅对应 menu_group_id / product_id
SELECT
    menu_group_id,
    product_id,
    COUNT(1)               AS 订单数,
    COUNT(DISTINCT userid) AS 用户数,
    ROUND(SUM(CAST(recharge_money AS DOUBLE)), 2) AS 总金额
FROM chamet_data.t_googlepay_recharge
WHERE recharge_status = 1
  AND order_status = 1
  AND SUBSTRING(CAST(pay_time AS STRING), 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
  AND userid <> 1
GROUP BY menu_group_id, product_id
ORDER BY 订单数 DESC
LIMIT 50
;
```

### 0.2 充值配置表中的订阅商品（辅助确认 product_id）

```sql
-- 从充值配置表找订阅类商品（字段以 DESC 为准，先抽样查看）
```

### 0.3 DWD 中 sdk_type / energy_type 分布（对账用）

```sql
-- 若渠道表订阅字段不明确，可用 DWD 辅助识别订阅充值类型
SELECT
    sdk_type,
    energy_type,
    COUNT(1)               AS 订单数,
    COUNT(DISTINCT userid) AS 用户数,
    ROUND(SUM(price), 2)   AS 总金额
FROM chamet_data.dwd_finance_recharge_i_d
WHERE ds BETWEEN '20260501' AND '20260531'
  AND SUBSTRING(recharge_time, 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
GROUP BY sdk_type, energy_type
ORDER BY 订单数 DESC

```

## 一、主查询：谷歌订阅 vs 谷歌总充值（用户数 + 金额 + 占比）

> 订阅识别：`product_id LIKE '%monthly_pass%'`（诊断 0.1 已确认）  
> 分母为谷歌渠道全部成功订单，非全站 DWD。

> **执行注意**：必须整段复制执行，以 `WITH` 开头；勿只选中中间 CTE 片段。

```sql
-- Chamet 5 月谷歌渠道：订阅 vs 谷歌总充值（2026-05）
WITH google_recharge AS (
    SELECT
        userid,
        CAST(recharge_money AS DOUBLE) AS amount_usd,
        product_id
    FROM chamet_data.t_googlepay_recharge
    WHERE recharge_status = 1
      AND order_status = 1
      AND SUBSTRING(CAST(pay_time AS STRING), 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
      AND userid <> 1
)
SELECT
    COUNT(DISTINCT IF(product_id LIKE '%monthly_pass%', userid, NULL)) AS 订阅用户数,
    COUNT(DISTINCT userid) AS 谷歌总充值用户数,
    ROUND(
        COUNT(DISTINCT IF(product_id LIKE '%monthly_pass%', userid, NULL)) * 100.0
        / NULLIF(COUNT(DISTINCT userid), 0),
        2
    ) AS 订阅用户占比_pct,
    ROUND(SUM(IF(product_id LIKE '%monthly_pass%', amount_usd, 0)), 2) AS 订阅总金额_USD,
    ROUND(SUM(amount_usd), 2) AS 谷歌总充值金额_USD,
    ROUND(
        SUM(IF(product_id LIKE '%monthly_pass%', amount_usd, 0)) * 100.0
        / NULLIF(SUM(amount_usd), 0),
        2
    ) AS 订阅金额占比_pct
FROM google_recharge
;
```

## 二、明细版：同时输出订单量（对齐「谷歌订阅占 3% 订单」）

```sql
-- Chamet 5 月谷歌渠道：订阅 vs 谷歌总充值（用户数 + 订单数 + 金额）
WITH google_recharge AS (
    SELECT
        userid,
        CAST(recharge_money AS DOUBLE) AS amount_usd,
        product_id
    FROM chamet_data.t_googlepay_recharge
    WHERE recharge_status = 1
      AND order_status = 1
      AND SUBSTRING(CAST(pay_time AS STRING), 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
      AND userid <> 1
)
SELECT
    COUNT(DISTINCT IF(product_id LIKE '%monthly_pass%', userid, NULL)) AS 订阅用户数,
    COUNT(DISTINCT userid) AS 谷歌总充值用户数,
    ROUND(
        COUNT(DISTINCT IF(product_id LIKE '%monthly_pass%', userid, NULL)) * 100.0
        / NULLIF(COUNT(DISTINCT userid), 0),
        2
    ) AS 订阅用户占比_pct,
    ROUND(
        SUM(IF(product_id LIKE '%monthly_pass%', amount_usd, 0)) * 100.0
        / NULLIF(SUM(amount_usd), 0),
        2
    ) AS 订阅金额占比_pct,
    SUM(IF(product_id LIKE '%monthly_pass%', 1, 0)) AS 订阅订单数,
    COUNT(1) AS 谷歌总充值订单数,
    ROUND(
        SUM(IF(product_id LIKE '%monthly_pass%', 1, 0)) * 100.0
        / NULLIF(COUNT(1), 0),
        2
    ) AS 订阅订单占比_pct,
    ROUND(SUM(IF(product_id LIKE '%monthly_pass%', amount_usd, 0)), 2) AS 订阅充值金额,
    ROUND(SUM(amount_usd), 2) AS 谷歌总充值金额
FROM google_recharge
;
```

## 三、按日趋势：谷歌订阅 vs 谷歌总充值

```sql
-- 每日谷歌订阅用户数、谷歌总充值用户数（2026-05）
WITH daily_total AS (
    SELECT
        SUBSTRING(CAST(pay_time AS STRING), 1, 10) AS dt,
        COUNT(DISTINCT userid) AS 谷歌总充值用户数
    FROM chamet_data.t_googlepay_recharge
    WHERE recharge_status = 1
      AND order_status = 1
      AND SUBSTRING(CAST(pay_time AS STRING), 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
      AND userid <> 1
    GROUP BY SUBSTRING(CAST(pay_time AS STRING), 1, 10)
),
daily_sub AS (
    SELECT
        SUBSTRING(CAST(pay_time AS STRING), 1, 10) AS dt,
        COUNT(DISTINCT userid) AS 订阅用户数
    FROM chamet_data.t_googlepay_recharge
    WHERE recharge_status = 1
      AND order_status = 1
      AND SUBSTRING(CAST(pay_time AS STRING), 1, 10) BETWEEN '2026-05-01' AND '2026-05-31'
      AND userid <> 1
      AND product_id LIKE '%monthly_pass%'
    GROUP BY SUBSTRING(CAST(pay_time AS STRING), 1, 10)
)
SELECT
    t.dt AS 日期,
    NVL(s.订阅用户数, 0) AS 订阅用户数,
    t.谷歌总充值用户数,
    ROUND(NVL(s.订阅用户数, 0) * 100.0 / NULLIF(t.谷歌总充值用户数, 0), 2) AS 订阅用户占比_pct
FROM daily_total t
LEFT JOIN daily_sub s ON t.dt = s.dt
ORDER BY t.dt
;
```

## 附录：全站口径（含 iOS / 三方支付等，非本文主口径）

> 若需与财务报表全渠道对齐，分母改用 `dwd_finance_recharge_i_d`：

```sql
-- 全站：订阅（谷歌）vs 全渠道总充值（2026-05）
WITH params AS (
    SELECT '20260501' AS ds_start, '20260531' AS ds_end,
           '2026-05-01' AS start_date, '2026-05-31' AS end_date
),
total_stat AS (
    SELECT
        COUNT(DISTINCT userid) AS 全站总充值用户数,
        ROUND(SUM(price), 2) AS 全站总充值金额_USD
    FROM chamet_data.dwd_finance_recharge_i_d
    WHERE ds BETWEEN (SELECT ds_start FROM params) AND (SELECT ds_end FROM params)
      AND SUBSTRING(recharge_time, 1, 10)
          BETWEEN (SELECT start_date FROM params) AND (SELECT end_date FROM params)
      AND userid <> 1
),
sub_stat AS (
    SELECT
        COUNT(DISTINCT userid) AS 订阅用户数,
        ROUND(SUM(CAST(recharge_money AS DOUBLE)), 2) AS 订阅总金额_USD
    FROM chamet_data.t_googlepay_recharge
    WHERE recharge_status = 1
      AND order_status = 1
      AND SUBSTRING(CAST(pay_time AS STRING), 1, 10)
          BETWEEN (SELECT start_date FROM params) AND (SELECT end_date FROM params)
      AND userid <> 1
      AND product_id LIKE '%monthly_pass%'
)
SELECT
    (SELECT 订阅用户数 FROM sub_stat) AS 订阅用户数,
    (SELECT 全站总充值用户数 FROM total_stat) AS 全站总充值用户数,
    ROUND(
        (SELECT 订阅用户数 FROM sub_stat) * 100.0
        / NULLIF((SELECT 全站总充值用户数 FROM total_stat), 0),
        2
    ) AS 订阅用户占比_pct,
    (SELECT 订阅总金额_USD FROM sub_stat) AS 订阅总金额_USD,
    (SELECT 全站总充值金额_USD FROM total_stat) AS 全站总充值金额_USD,
    ROUND(
        (SELECT 订阅总金额_USD FROM sub_stat) * 100.0
        / NULLIF((SELECT 全站总充值金额_USD FROM total_stat), 0),
        2
    ) AS 订阅金额占比_pct
;
```

## 备注

| 项 | 说明 |
|---|---|
| 主口径 | **谷歌渠道** `t_googlepay_recharge`，分子分母同表 |
| 订阅识别 | `product_id LIKE '%monthly_pass%'`（chamet/chillchat/matemet 谷歌月订阅） |
| 订单占比 | 方案二 `订阅订单占比_pct` 应对齐「谷歌订阅占谷歌总订单 3%」 |
| `t_googlepay_recharge` 无 `ds` | 渠道订单表为全量快照，**必须用 `pay_time` 限定时间**，勿写 `WHERE ds=...` |
| ODPS 执行 | 必须整段执行（含 `WITH`）；单行汇总用条件聚合 `IF(...)`，勿拆 CTE 片段 |
